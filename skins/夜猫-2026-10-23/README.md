# 夜猫 · 2026-10-23

**定位**：奶油猫的夜间版：梅子紫的夜色、奶油色的字、粉色猫耳和肉垫。只用通用的动物特征，不画、不借用任何现成角色。设计和取舍见 [可爱风格调研](../调研-可爱风格-2026-10-23.md)。

## 各元素

- 面板：圆角 18，梅子紫底，1.5 点紫灰描边。
- 卡片：深紫软垫；底色和描边从上沿让出 6 点，留给耳朵。
- 选中：玫瑰紫底、2 点粉边，一对粉色猫耳立在卡片上沿，选中时弹上来。
- 悬停：杏色 1.5 点细边加一层淡底。
- 标签：当前标签是紫色胶囊，两只粉色小猫耳；拖入时粉色虚线。
- 搜索结果：选中行是玫瑰紫胶囊加粉边。
- 键帽：深紫键帽，两只三角耳伸出 3 点。
- 快捷键提示、提示浮窗：右上角一枚粉色肉垫。
- 字体：系统圆体（英文和数字是圆体，中文是苹方），字号和粗细由各模块决定。
- 动效：选中框弹簧滑动（0.34 秒，带一点回弹），耳朵和角标从卡片后面弹上来；悬停原地淡入（0.12 秒）。开启“减少动态效果”时一律直接切换。
- 增强对比度：描边加粗，耳朵保留。
- 装饰都画在文字和缩略图下面；面板本身不往外画，面板上的装饰只放在留白里。
