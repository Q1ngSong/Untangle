# 可爱动物皮肤调研与方案 · 2026-10-23

目的：为 Untangle 设计一批可爱的动物皮肤（猫、企鹅、熊猫，另加兔、柴犬、小熊），做成只含数据的皮肤包（[格式](FORMAT.zh-CN.md)）。
本文先是提案；用户的选择和做成的包见第七节。对比页（私有 Artifact）：[Untangle 可爱皮肤](https://claude.ai/artifact/TMU5YKwjZBpWoSJugo9fpw)，
六套方案的效果图并排，可看动效，勾选后复制选择。

## 一、调研结论

### 可爱风界面的常见做法

- **颜色**：粉彩底配糖果色点缀；描边和文字用深可可色或海军蓝，保证读得清（daisyUI 的 Kawaii UI 趋势页）。
- **形状**：大圆角、胶囊形控件，小圆点、云朵、爱心、动物耳朵这类圆润的小图形。
- **装饰的位置**：信息密度低到中，装饰集中在边缘；关键操作和文字周围留干净的空白。
- **动作**：轻快的小跳、弹一下、眨眼；不做长时间循环。
- **软萌立体**（claymorphism）：内阴影上亮下暗，圆角，浅色面；容易显得幼稚，要靠克制的字体和足够的对比压住（Smashing Magazine）。

### 两个风险

- **版权**：Hello Kitty、酷企鹅、大耳狗（三丽鸥），迪士尼，LINE FRIENDS，轻松熊（San-X），熊本熊，Pusheen，Pingu，Molang 都是注册角色。
  - 只用通用的动物特征：耳朵、爪印、毛色、尾巴、企鹅的白肚皮。
  - 不画出像某个角色的组合，例如“白猫 + 蝴蝶结 + 没有嘴”“棕熊 + 黄色胸口”“黑熊 + 红脸蛋”。
  - 名字也不沿用任何角色名。
- **可读性**：装饰一抢眼就压过窗口标题。所以装饰只画在内容下面和留白里，正文对比度不低于 4.5:1（实际都在 5:1 以上）。

## 二、格式能画什么（读引擎代码得到的）

引擎：`Sources/OverlayKit/SkinStyle.swift`（读包）、`PackageSkin.swift`（绘制）。

| 想要的效果 | 怎么画 | 限制 |
|---|---|---|
| 角上的小图：耳朵、爪印、企鹅头 | 九宫格 PNG，只有角里有图案，边和中间透明。九宫格的角不拉伸，所以元素多宽，耳朵都在角上 | 只能贴四个角，放不到某条边的正中 |
| 画出元素外面 | 图层 `inset` 写负数、`clip: false` | 最多 4 点（`PackageSkin.margin`）。标签（最多 3 点，标签栏只留这么多）、键帽可以；**面板不行**：`OverlayHost` 把窗口设成面板的大小；**切换器里的卡片也不行**：滚动区域按卡片边缘裁切，上下左右都裁（做的时候在 App 渲染里发现的） |
| 圆耳、肉垫、腮红 | `box`，外形 `rounded`、半径取边长一半就是圆；颜色可引用变量，工坊里能改 | 只有矩形类外形，三角耳、水滴形垂耳、卷尾要用图片，颜色固定在图里 |
| 沿一条边重复的花边（蜂蜜滴） | `tile` 平铺一张很高的透明 PNG（每边不超过 4096 像素），只有最上面一条有图案 | 平铺从左上角开始，只能做上边或左边 |
| 底纹 | 小块 PNG `tile` 平铺（圆点、蜂巢）；或程序纹理 `pattern` | `pattern` 的 `dots` 是方点；底纹只在卡片之间的缝里看得到 |
| 耳朵藏在卡片后面 | 选中状态用 `add`，图层顺序：耳朵 → 不透明的选中底色 → 描边。耳朵根被底色盖住 | 用 `replace` 时选中框不会滑动；所以选中的这一组要整块放在 `add` 里 |
| 选中框滑过去 | 状态的过渡写 `slide: true`，画在内容下面的 `add` 图层一起滑；画在内容上面的原地淡入 | 悬停没有自己的过渡时沿用选中的曲线，但不滑 |
| 耳朵弹上来 | 关键帧 `offset` + `opacity`，`on: enter` | `scale`、`rotation` 绕整个图层区域的中心，不能让一只耳朵单独转或缩放 |
| 圆体字 | `"system": true, "design": "rounded"` | 中文仍是苹方；包内字体用固定字号，每种用途可以引用不同字号的字体变量 |

各模块的留白（装饰能放的地方），单位是点：

| 模块 | 留白 | 说明 |
|---|---|---|
| 切换器 | 面板 10，卡片 7 | 卡片头部高 20，图标 16；标题字形顶部约在卡片 y = 11 |
| Dock 预览 | 面板 8，卡片 7 | 同切换器卡片 |
| 搜索面板 | 顶部输入区 52，列表上下 6、左右 6 | 结果行高固定 44，行内左右 10 |
| 快捷键提示 | 14 | 键帽 12 点字，左右 6、上下 3，高约 21 |
| 提示浮窗 | 14–16 | 宽度随内容 |
| 标签栏 | 3 | 标签上下各留 3 点，所以标签上的耳朵最多伸出 3 点 |

由此得到放装饰的规矩：

- 卡片上的装饰全部画在卡片里面：卡片的底色和描边从上沿往下让出 6 点（各状态都让，卡片不会跳），耳朵立在这 6 点里。
- 卡片右上角的小图要在标题字形（从 y = 11 起）上方，企鹅头直径约 10.6 点。
- 标签上的耳朵伸出 3 点，当前标签的底色从上沿让出 3 点，耳朵一共露出约 6 点。
- 搜索结果行之间没有空隙，选中行不往外画，否则会盖住上一行的字。

## 三、六套共用的规则

1. 字和缩略图永远在最上层；装饰画在内容下面、留白里。
2. 面板不透明；选中同时用底色、2 点描边和动物记号表示。
3. 大圆角：面板 18、卡片 14、缩略图 9，标签和搜索结果是胶囊形。皮肤只管画，不改尺寸。
4. 字体默认系统圆体，标题中等粗细；可选“标题用站酷快乐体”（Google Fonts，SIL OFL 1.1，TTF 约 1.5 MB；做之前要核对常用字覆盖）。
5. 动效二选一：
   - 弹跳：选中框弹簧滑动，约 0.34 秒，带一点回弹；耳朵和角标从卡片后面弹上来。
   - 安静：平滑滑动 0.2 秒，装饰直接出现。
   - 开启“减少动态效果”时一律直接切换（引擎规则）。
6. 增强对比度：去掉底纹，描边加粗 1 点，耳朵保留。
7. 工坊可调：选中色、悬停色；用 `box` 画的圆耳、腮红颜色也可调。图片里的耳朵颜色固定，所以图片耳朵的方案不开放选中色以外的调整。

## 四、方案

色值都是浅色版；深色版另列。对比度：正文与面板都在 9:1 以上，次要文字 5:1 以上，选中描边与面板约 3:1。

### 1. 奶油猫 Cream Cat（建议）

奶茶底、粉色肉垫，暖和、居家。深色版“夜猫”。

| 项 | 浅色 | 夜猫 |
|---|---|---|
| 面板 / 描边 | `#FFF8F1` / `#E8CFBA` | `#2B2431` / `#483D55` |
| 文字 / 次要 | `#4A3428` / `#7E6455` | `#FAEFE7` / `#C9B7C4` |
| 卡片 / 缩略图底 | `#FFFFFF` / `#F6ECE2` | `#352C3E` / `#2E2737` |
| 选中描边 / 底色 | `#E0648F` / `#FFE7EF` | `#FF92B6` / `#4B3347` |
| 悬停 | `#E59A6C` | `#E8AC84` |
| 肉垫、耳内 | `#F2A0BC`、`#FFD3E1` | `#FF92B6`、`#FFC2D6` |

- 面板：圆角 18，奶油底，1.5 点奶茶色描边。
- 卡片：白色软垫，内阴影上亮下暗。选中时粉色底、2 点粉边，从上沿探出一对粉色猫耳（耳内浅粉）。
- 悬停：蜜桃色 1.5 点细边加一层很淡的底色。
- 标签：当前标签白色胶囊，两只小猫耳伸出 3 点；悬停淡底；拖入时粉色虚线。
- 搜索结果：粉色胶囊底加粉边。
- 键帽：白色圆角键帽，奶茶色描边，两只三角耳伸出 3 点，像一排小猫头。
- 快捷键提示、提示浮窗：右上角留白里一枚 12 点的粉色肉垫。
- 用到：九宫格角饰 PNG（耳朵、肉垫）、伸出 4 点、内阴影、弹簧滑动、关键帧弹起。

## 五、建议

- 第一批做你点名的三种：**奶油猫**（浅色 + 夜猫）、**冰川企鹅**（浅色 + 极夜）、**竹林熊猫**（浅色）。
- 垂耳兔、蜂蜜小熊以后再加；柴犬和奶油猫太像，二选一。
- 每套一个包，深色版是单独的包（`appearance` 是整包的属性）。
- 每个包按 `skins/像素方块-2026-10-23/package/` 的结构：`skin.json`，`assets/` 用 Pillow 画出 2 倍图（1 像素 = 0.5 点），`previews/card.png`（640×400），`README.md`；方案文件夹里放 README 和效果图。

## 七、用户的选择与实现（2026-10-23）

- 六套都做；有深色版的三套（奶油猫、冰川企鹅、蜂蜜小熊）浅深两套都要，其余只做浅色。共九个包：
  奶油猫、夜猫、冰川企鹅、极夜企鹅、竹林熊猫、垂耳兔、柴犬、蜂蜜小熊、可可熊。
- 都用系统圆体；动效“弹跳”，竹林熊猫“安静”。
- 九个包由 `make-cute-packages.py`（本地素材生成工具） 生成：素材用 Pillow 画（8 倍超采样后缩到 2 倍），
  `skin.json` 和两份 README 也从同一份数据写出；`--renders <画廊目录>` 用画廊截图合成效果图和预览卡片。
- 做的时候改过的地方：
  - 切换器的滚动区域会裁掉卡片外沿以外的部分，耳朵、企鹅头、垂耳、尾巴都收进卡片里面（见第二节）。
    方案页上伸出卡片 4 点的画法只在标签和键帽上保留。
  - 垂耳兔的耳朵只有 7 点宽，白色加描边看起来像一对括号；改成实心粉色，耳根沿卡片上沿搭过角，再顺着两侧垂下来。

## 八、垂耳兔重做（2026-10-23）
