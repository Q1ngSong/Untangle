# 蜂蜜小熊 · 2026-10-23

**定位**：奶油、蜂蜜黄和焦糖棕：选中卡片冒出一对圆耳，面板上沿淌着蜂蜜，底纹是淡淡的蜂巢。只用通用的动物特征，不画、不借用任何现成角色。设计和取舍见 [可爱风格调研](../调研-可爱风格-2026-10-23.md)。

## 各元素

- 面板：圆角 18，奶油底，淡淡的蜂巢格底纹（平铺 PNG）；上沿留白里淌着一圈蜂蜜（顶边平铺）。
- 卡片：白色；底色和描边从上沿让出 6 点。选中时浅蜜色底、2 点蜂蜜边，冒出一对棕色圆耳（内耳浅棕）。
- 悬停：焦糖色细边加淡底。
- 标签：当前标签白色胶囊，两只小圆耳；标签栏留白只有 3 点，不淌蜂蜜。
- 搜索结果：选中行是浅蜜色胶囊加蜂蜜边。
- 键帽：蜂蜜色，底边深一层。
- 快捷键提示：右下角一枚熊掌印。
- 熊耳是 `box` 色块，工坊里能改颜色。
- 字体：系统圆体（英文和数字是圆体，中文是苹方），字号和粗细由各模块决定。
- 动效：选中框弹簧滑动（0.34 秒，带一点回弹），耳朵和角标从卡片后面弹上来；悬停原地淡入（0.12 秒）。开启“减少动态效果”时一律直接切换。
- 增强对比度：描边加粗，去掉底纹，耳朵保留。
- 装饰都画在文字和缩略图下面；面板本身不往外画，面板上的装饰只放在留白里。
