# 薰衣草兔 · 皮肤包

格式见 `../../FORMAT.zh-CN.md`，设计见 `../../调研-可爱风格-2026-10-23.md`。奶白和薰衣草紫：选中卡片角上探出一只小兔子头，标签和搜索结果的图标戴着兔耳。

- `assets/badge.png`：选中卡片右上角的小兔子头（九宫格右上角，约 10 点，在标题文字上方）；`assets/row-ears.png`、`assets/tab-ears.png`：选中的搜索结果和当前标签里，图标长出的兔耳；`assets/key-ears.png`：键帽两个上角的长耳朵；`assets/sticker.png`：角上的小兔子头。
- 所有素材由 `skins/make-cute-packages.py` 用 Pillow 画出：2 像素 = 1 点（`"scale": 0.5`），全部原创，CC0。
- 装饰都画在文字和缩略图下面；面板本身不往外画，面板上的装饰只放在留白里。
- 字体：系统圆体（`"design": "rounded"`），字号和粗细由各模块决定。
- 动效：选中框弹簧滑动（0.34 秒，带一点回弹），耳朵和角标从卡片后面弹上来（`pop`）；悬停原地淡入。开启“减少动态效果”时一律直接切换。
- 增强对比度：描边加粗；耳朵保留。
- 工坊可调：选中色、悬停色。图片里的耳朵颜色固定。
