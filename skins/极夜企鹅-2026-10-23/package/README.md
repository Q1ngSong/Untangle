# 极夜企鹅 · 皮肤包

格式见 `../../FORMAT.zh-CN.md`，设计见 `../../调研-可爱风格-2026-10-23.md`。冰川企鹅的深色版：面板是企鹅深蓝的背，卡片是白肚皮，飘着很淡的雪点。

- `assets/badge.png`：选中卡片右上角的小企鹅（九宫格右上角，直径约 10.6 点，在标题文字上方），不出卡片；`assets/tab-feet.png`、`assets/key-feet.png`：当前标签和键帽底下露出的两只橙色小脚；`assets/sticker.png`：右上角的雪花。
- 格式只能贴四个角，所以两只脚分在两边，不在底边正中。
- 所有素材由 `skins/make-cute-packages.py` 用 Pillow 画出：2 像素 = 1 点（`"scale": 0.5`），全部原创，CC0。
- 装饰都画在文字和缩略图下面；面板本身不往外画，面板上的装饰只放在留白里。
- 字体：系统圆体（`"design": "rounded"`），字号和粗细由各模块决定。
- 动效：选中框弹簧滑动（0.34 秒，带一点回弹），耳朵和角标从卡片后面弹上来（`pop`）；悬停原地淡入。开启“减少动态效果”时一律直接切换。
- 增强对比度：描边加粗；耳朵保留。
- 工坊可调：选中色、悬停色。图片里的耳朵颜色固定。
