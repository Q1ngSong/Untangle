# 皮肤方案归档

这里收录皮肤工坊里的每一套皮肤方案，一套一个文件夹。

## 命名

文件夹名为 **方案名-日期**，日期是这一版设计定稿的日期（YYYY-MM-DD）。
同一方案重新设计时新建一个文件夹，旧文件夹保留，作为设计演变的记录。

## 每个文件夹里有什么

| 文件 | 说明 |
|---|---|
| `README.md` | 设计说明：定位、配色、外形、材质、选中与悬停、动效、无障碍、对应代码 |
| `<方案>.untangle-theme.json` | 整套皮肤文件，可在 设置 → 皮肤工坊 → 导入主题 直接导入，六个模块全部套用 |
| `previews/` | 标签栏、切换器、Dock 预览、搜索面板、快捷键提示、提示浮窗的效果图（同一张繁杂桌面背景） |

## 新增一套方案时

1. 按 [皮肤包格式](FORMAT.zh-CN.md) 和现有 `package/` 示例制作 `skin.json` 与素材，打包成 `.untangleskin`。普通新皮肤不需要修改 App 的内置模板枚举。
2. 在这里新建 `方案名-日期/`，写设计说明，保留包及六个模块的效果图；需要保存跨模块搭配时另导出主题文件。
3. 在工坊中验证安装、调整、导出及重新导入，再更新本页的“现有方案”表。调整内置模板属于单独的 App 代码改动。

皮肤只管画成什么样；尺寸、间距、栏高等模块功能在各模块面板里调，不属于皮肤。整套主题文件和本地标签模板仍可携带栏高，其他模块布局设置不随皮肤导入。
