# 皮肤方案调研与扩充建议 · 2026-10-23

目的：找出常见、受欢迎的皮肤方案，决定下一批实现哪些。本文是提案，确认前不实现。

## 一、调研结论

### 配色体系（开发者工具里最常见）

- Neovim 配色按安装量排序，Catppuccin 第一、Tokyo Night 第二，Kanagawa、Rosé Pine 在后面（Dotfyle）。
- VS Code 圈里 One Dark Pro 与 Dracula 最主流，Catppuccin 是近年上升最快的（编辑类榜单，偏主观）。
- 终端与 TUI 工具常把 Dracula、Nord、Catppuccin、Gruvbox、Tokyo Night 打包成内置主题（ratatui-themes、pi-themes）。
- Raycast 的主题由 **底色、主文字、次要文字、强调色** 组成，深浅色可各选一套，可用链接分享；AltTab 也提供一组内置配色。

### 界面风格（2026）

- **玻璃**已是系统级标准（macOS Liquid Glass、Windows Fluent），新版本降低了默认透明度，繁杂背景下要保证可读性。
- **新粗野主义**（粗黑边、硬投影、高饱和平涂）作为点缀仍然有效，不适合信息密集的界面整页使用。
- **复古 / Y2K / 拟物**（果冻高光、铬、纸张）作为怀旧小众风格回潮。
- **新拟态**因对比度低、按钮难辨认，已基本退出实际产品，不建议做。

## 二、对我们架构的影响

现在每个模板的**底色和文字色写死在代码里**，皮肤数据只开放了强调色和悬停色。所以：

- **配色类方案**：先把底色、主文字、次要文字开放成皮肤数据（旧皮肤缺省时取模板原值，兼容不变），
  之后每套配色只是一份数据预设，可以一次加很多，也能被导入导出、分享。
- **风格类方案**：需要新的绘制代码（像赛博朋克的 `CyberpunkSkin.swift`），每套单独设计。

两类方案都放在 `skins/` 下，一套一个文件夹。

### B. 风格类（各自需要新绘制）

| 方案 | 看点 | 成本 | 建议 |
|---|---|---|---|
| 新粗野主义 | 粗黑边 2–3 点、向右下的硬投影（画在面板内）、高饱和黄/粉平涂、直角 | 中 | 推荐：和现有三套差异最大 |
| 终端 CRT | 单色磷光绿或琥珀、等宽标题字、扫描线、轻微发光，复用赛博朋克的扫描线和发光 | 低 | 推荐：成本低、辨识度高 |
| 复古 Aqua | 果冻高光的蓝色选中、细条纹底、玻璃珠质感按钮，致敬早期 Mac OS X | 中高 | 可选：怀旧，但要避免和系统控件冲突 |
| 合成波 | 紫粉日落渐变、透视网格、霓虹描边 | 中 | 暂缓：和赛博朋克重叠较多 |
| 纸张 / 墨水 | 纸纹、衬线标题、纯黑白 | 低 | 暂缓：和极简接近 |
| 新拟态 | 柔和浮雕 | — | 不做：对比度不足 |

## 四、建议的第一批

1. **开放底色、主文字、次要文字**为皮肤数据，工坊里可调；旧皮肤保持原样。
2. 新增“纯色”风格，带 **Catppuccin Mocha、Catppuccin Latte、Tokyo Night、Nord、Dracula、Gruvbox Dark** 六套配色。
3. 新增两套风格：**终端 CRT**、**新粗野主义**。
4. 每套方案在 `skins/方案名-日期/` 归档：设计说明、可导入皮肤文件、六张效果图。

配色值取自各方案官方调色板；它们都是开源配色，名称沿用原名，只取颜色，不使用其标志。
