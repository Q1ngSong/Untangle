# 赛博朋克 · 皮肤包示例

格式见 `../../FORMAT.zh-CN.md`。这个包只有 `skin.json` 和效果图，没有图片素材：所有效果都由引擎的图层画出来。
1.1.0 按 App 内置赛博朋克的绘制代码逐项复刻，形状、颜色、透明度、线宽和动画时长都与内置版一致，并经过逐帧录屏对照。

- 底：系统模糊材质 + 上浅下深的紫黑渐变 + 每 3 点一条的静态扫描线。
- 边：洋红描边错开 1.5、1 点，青色细描边，切角用青色实线点亮，内发光；左上角一段青条加一段洋红条。
- 标签：每个标签有淡青色细边；悬停的标签淡洋红底、洋红边；当前标签青色渐变底、青色边、发光，底部一条青 → 洋红的下划线。
- 卡片、搜索结果：选中是青色渐变底、青色边、发光和左边缘色条；悬停是淡洋红底和洋红边。
- 动效：选中时渐变底从原来的位置滑到新位置（0.2 秒平滑），边框、发光和下划线原地淡入淡出；悬停原地淡入淡出（卡片 0.12 秒）。
- 工坊可调：强调色、次要色、切角、发光、背景不透明度。
