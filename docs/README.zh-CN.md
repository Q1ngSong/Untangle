## 功能一览

| | |
| --- | --- |
| **布局** | 用键盘放到半屏、四角、最大化、居中；拖到屏幕边缘吸附，或拖动时用网格；一键退回；区域碰撞（Beta）。 |
| **标签组** | 不同应用的窗口共用一条标签栏，点标签只把那一个窗口提到最前。 |
| **工作空间** | 把一个桌面的窗口、标签组、浏览器标签页和编辑器项目存成案板，随后在专属桌面上重新打开。 |
| **窗口切换器** | **⌘ Tab** 列出每一个窗口和实时缩略图；允许后还能列出 Chrome 标签页。 |
| **Dock 预览** | 悬停 Dock 图标查看应用的窗口，点哪张就把哪个窗口提到最前。 |
| **命令搜索** | 按名称搜索命令、已打开的窗口和保存的案板，支持中文、英文和拼音。 |
| **桌面** | 新建、删除、切换、清理桌面；把窗口送到别的桌面或显示器。 |
| **菜单栏（Beta）** | 把菜单栏图标分成带颜色的几行，在托盘里切换，不再被刘海挡住。 |
| **外观与皮肤** | 液态玻璃（浅色或深色）或经典外观；皮肤工坊逐个模块调；18 款现成皮肤包。 |
| **设置** | 自定义总入口键和快捷键；换电脑时把全部设置打包成一个 zip 带走。 |

## 快速开始

1. 将 `Untangle.app` 放入“应用程序”并打开。
2. 在**设置 → 诊断 → 权限**中开启**辅助功能**，用于控制窗口与全局输入；开启**屏幕录制**以显示窗口缩略图。首次缺少辅助功能权限时，Untangle 会自动打开诊断页面。
3. 聚焦一个窗口，按住**右 Command**，再按 **←**，将窗口放到左半屏。输入按键序列时保持按住总入口键。
4. 在**设置 → 快捷键**中选择总入口键，搜索或筛选命令，录制自定义快捷键。点击**录制**预览输入，**保存**后生效；未保存时按 **Esc** 取消。

在**设置 → 通用 → 语言**中选择**跟随系统**、**简体中文**或 **English**，更改立即生效。命令搜索支持中英文名称，也支持拼音。

下文使用默认按键，你保存的快捷键优先。**⌘ Tab** 等独立快捷键不需要先按总入口键。

## 布局：用键盘摆放窗口

![按住总入口键并按左方向键，窗口移动到桌面左半屏的动画示意。](assets/layout-demo.svg)

*动画是操作示意，不是实际录屏。窗口内容与材质取决于应用及系统外观；开启“减少动态效果”时显示静态画面。*

### 键盘分屏

> 以前：拖着边框一点点对齐，总差几个像素。

按住总入口键再按 **←**，窗口贴到左半屏；**→ ↑ ↓** 同理。**F** 最大化，**C** 居中。

执行后 Untangle 会等你继续按键：再按一次 **←**，窗口依次占屏幕的 1/2 → 1/3 → 2/3，再回到 1/2。等待时间在**设置 → 快捷键**中调整。

### 四角排列

> 以前：四个窗口叠成一摞，互相挡着。

按住总入口键，分别按 **U / I / J / K**，把窗口放进左上、右上、左下、右下四个角。

| 按住总入口键后输入 | 功能 |
| --- | --- |
| **← / → / ↑ / ↓** | 左、右、上、下半屏 |
| **U / I / J / K** | 左上、右上、左下、右下四分之一屏 |
| **F** | 最大化 |
| **C** | 居中 |
| **Z** | 回到上一次的位置 |
| **Space** | 打开命令搜索 |

### 拖动吸附与网格

> 以前：系统分屏只有左右两半，想要三分之一做不到。

把窗口拖到屏幕边缘即可吸附。拖动时按住网格修饰键（默认 Option），屏幕上出现网格，框住几格窗口就占几格。网格的行数和列数在**设置 → 布局**中设置。

窗口间距和动画时长也在这里调。使用液态玻璃外观时，吸附预览可以是一块真正的玻璃。如果系统自带的拖动平铺开着，布局页面会指出哪几项和 Untangle 重叠，并帮你打开“桌面与程序坞”设置。

### 一键退回

> 以前：手滑摆错，原来的位置再也找不回来。

按住总入口键再按 **Z**，窗口回到刚才的位置。标签移错了组、区域边界拉错了，也能用 **Z** 退回去。

### 区域碰撞（Beta）

> 以前：拉宽左边的窗口，右边的就被盖住一截。

打开后，改一个窗口的大小时，贴着它的窗口沿共用的边让开或贴上。半屏、四个角和拖动吸附也会按这些边界放进区域；按 **Z** 可以把整条边界退回去。默认关闭，在**设置 → 布局**中打开。

## 标签组：把相关应用放在一起

![点击标签，标签组从浏览器窗口切换到笔记窗口的动画示意。](assets/tabs-demo.svg)

### 跨应用标签组

> 以前：浏览器、笔记、文稿叠在一起，要找就得一个个翻。

不同应用的窗口共用一条标签栏、一块屏幕区域。点一个标签，只有那个窗口提到最前，同一应用的其他窗口留在原处。

有四种建组方式：

- 按住总入口键，依次输入 **T、T**，合并当前窗口下方被覆盖的窗口。交集占任一窗口面积超过 **85%** 即可加入，边缘不必对齐。
- 输入 **T、A**，再点选任意窗口加入。
- 把窗口吸附或摆到另一个窗口（或标签组）正好占着的区域，停稳后两者自动合成一组。可在**设置 → 标签组**中开关。
- 按住 **⌘** 把窗口拖到标签栏上。

### 拖出、拖入、放回

> 以前：合错了组，只能全部解散重来。

| 按键或手势 | 功能 |
| --- | --- |
| **[** / **]** | 上一个 / 下一个标签 |
| **T、数字** | 切到第 N 个标签 |
| 拖动标签 | 调整顺序、拖进另一个组的标签栏，或拖出来变回独立窗口 |
| 按住 **⌘** 拖动窗口 | 让它离开原来的标签组 |
| **T、X** | 把当前窗口移出标签组 |
| **T、U** | 解散标签组 |
| 总入口键 + **Z** | 把移走的标签放回原来的组 |

打开调度中心、应用程序窗口或显示桌面时，标签栏会自动隐藏。标签栏的高度、间距和宽度在**设置 → 标签组**中调整，外观在皮肤工坊里调。

## 找窗口：需要哪个，马上找到

![窗口切换器的选中透镜在各窗口卡片之间移动的动画示意。](assets/switcher-demo.svg)

### 窗口切换器

> 以前：系统 ⌘Tab 只有应用图标，同一个应用开了三个窗口分不清。

**⌘ Tab** 在所有窗口之间切换，每个窗口一张实时缩略图，选中哪个就切到哪个。**⌘ `** 只切同一个应用的窗口，加上 **⇧** 反向切换。

已最小化的窗口显示最后的画面，不会被还原。可以选单行滚动或多行排列、调整缩略图高度，也可以决定是否列出已最小化的窗口。

### Chrome 标签页直达

> 以前：标签页藏在某个 Chrome 窗口里，切过去还要再找。

在**设置 → 页面**中开启后，切换器里 Chrome 窗口的卡片下会列出它的标签页：按 **↓ ↑** 选中，松开就切过去，Chrome 不会重新加载页面。命令搜索里每个标签页也能单独搜到。需要允许 Untangle 读取 Chrome 标签页的标题和网址，无痕窗口不会列出。

### 命令搜索

![在命令搜索里输入首字母，列出匹配命令、窗口和案板的动画示意。](assets/search-demo.svg)

> 以前：快捷键记不住，菜单里翻来翻去，不记得功能在哪。

按住总入口键再按 **Space**，输入命令名（如“左半屏”）、应用名、窗口标题或案板名称。中文、英文和拼音都能匹配，例如输入 `zbp` 就能找到“左半屏”。用 **↑ ↓** 和回车执行，也可以直接点击；**Esc** 回到原来的窗口。

每个命令旁边都标着它的按键序列，搜索也是学快捷键的好办法。

### 按键提示

> 以前：按住右 ⌘ 之后，忘了下一个键是什么。

按下总入口键，提示面板会列出下一步可以按的键：← 左半屏、F 最大化、T 标签组、D 桌面、W 工作空间、Z 退回……总入口键和每个快捷键都可以在**设置 → 快捷键**中改。

## Dock 预览：先看看是哪个窗口

![悬停 Dock 图标，弹出各窗口缩略图并选中其中一个的动画示意。](assets/dock-demo.svg)

> 以前：鼠标放到 Dock 上，只看到一个应用名；点进去才发现开的不是想要的那个窗口。

### 悬停预览

鼠标停在 Dock 图标上，这个应用的每个窗口都会显示一张缩略图，点哪张就把哪个窗口提到最前。预览贴着 Dock 所在的那一边弹出，Dock 放在左、右、下方都可以。

- **已最小化的窗口**也有缩略图，显示最后的画面，不会被还原。
- **只看当前桌面：** 其他桌面上的窗口不出现在预览里。
- **只有一个窗口的应用**是否也预览，可以自己选。
- **显示延时、关闭延时**分别可调，避免鼠标划过 Dock 时预览乱跳。
- **预览动画：** 从 Dock 一侧淡入、轻轻滑出，在图标之间移动时平滑跟随，关闭时淡出；开启“减少动态效果”时直接显示。
- **隐藏 Dock 自带的名字：** 预览出现时不再叠着系统的应用名标签（Dock 的放大效果会一起关闭）。

### 设置与权限

在**设置 → Dock 预览**中调整以上选项；预览卡片的样子在皮肤工坊里调。缩略图需要**屏幕录制**权限，没有授权时缩略图是空的，其他功能照常可用。

## 桌面：不用进调度中心

![空桌面消失、其余桌面靠拢的动画示意。](assets/desktops-demo.svg)

### 桌面快速管理

> 以前：新建桌面要进调度中心、找到右上角的 +。

| 总入口键后输入 | 功能 |
| --- | --- |
| **D、N** | 新建桌面并切过去 |
| **D、X** | 删除当前桌面 |
| **D、数字** | 直接跳到第 N 个桌面 |
| **D、[** / **D、]** | 切到左边 / 右边的桌面 |

在**设置 → 布局**中还可以让 Untangle 接管 **⌃←**、**⌃→** 和 **⌃数字**，切换桌面不用等系统动画。

### 窗口送到别处

> 以前：拖着窗口撞屏幕边，等它慢慢翻到下一个桌面。

| 总入口键后输入 | 功能 |
| --- | --- |
| **S、数字** | 把当前窗口送到第 N 个桌面 |
| **S、←** / **S、→** | 送到左边 / 右边相邻的桌面 |
| **D、← / → / ↑ / ↓** | 送到另一块显示器 |

### 清理空桌面

> 以前：开到桌面 7，一半是空的。

按住总入口键输入 **D、C**，一次删掉所有空桌面。隐藏或最小化的窗口不算占用；每块屏幕至少保留一个普通桌面，状态读不准的桌面会保留下来。

### 调度中心直接展开（Beta）

> 以前：调度中心顶上只有一排桌面名字，要再把鼠标移上去才展开。

打开后，按 **⌃↑** 或在触控板上滑进入调度中心时，桌面缩略图已经展开，不需要移动鼠标；下滑或再按一次 **⌃↑** 退出。默认关闭，在**设置 → 布局**中打开。

## 工作空间：明天打开，还是今天的样子

![打开保存的工作空间，恢复窗口布局和标签组的动画示意。](assets/workspace-demo.svg)

### 案板一键恢复

> 以前：每天早上把十几个窗口重新开一遍、摆一遍。

一个案板对应单个显示器上的一个桌面。它保存窗口的位置和大小、Untangle 标签组、Chrome／Safari 标签页，以及 VS Code 本地文件和项目。

按住总入口键输入 **W、数字**打开案板：Untangle 给它一个专属桌面，启动缺失的应用，打开记录的文件和网页，把窗口挪过来并重建标签组，没有到位的内容会提示出来。已经打开的案板直接切到它的桌面。

- **检查点：** **W、S** 保存当前状态，**W、R** 回到检查点。
- **自动保存：** 按你设定的间隔保存，离开、释放和退出时也会保存；空桌面不会覆盖检查点。
- **打开后聚焦：** 在布局预览里点一个窗口或标签，指定打开后最前面的窗口。
- **锁定：** 锁定后，保存的内容和布局不会被覆盖。
- **回收站：** 删除的案板保留 7 天，期间可以还原。
- **释放：** **W、X** 解除案板和桌面的绑定。

读取浏览器需要允许自动化权限。未保存的编辑、浏览器配置文件及远程编辑器会话不属于备份内容。

### 案板列表

> 以前：开了好几个桌面，不记得哪个在做什么。

按 **⌥W**（或总入口键 + **W、Space**），左侧列出所有案板和它们的布局预览。已经打开的案板直接切过去，没打开的新建桌面再恢复。在**设置 → 工作空间**中拖动案板，可以调整它们的数字顺序。

[学习工作空间命令](COMMANDS.md) →

## 菜单栏管理（Beta）：图标太多也不怕刘海

![在托盘中选择第 2 行，菜单栏刘海旁换成这一行图标的动画示意。](assets/menubar-demo.svg)

> 以前：菜单栏图标一多，右边的就被刘海挡住，想点也点不到。

### 把图标分成几行

在**设置 → 菜单栏 · Beta** 中，把菜单栏里的图标分到第 1、2、3……行。菜单栏一次只显示一行，其余的行先收起来；需要哪一行就切到哪一行。

- **拖进行里：** 在设置页把“已发现的项目”拖到某一行，或者按住 **⌥⌘** 把菜单栏上的图标拖进托盘里的某一行。同一个图标可以同时放在好几行。
- **常驻图标：** 把图标拖回菜单栏，它就一直显示，不跟着行切换。
- **每行一种颜色：** 可以给每一行选背景颜色（琥珀、海蓝、陶土、石墨、松绿、靛蓝、紫灰、玫瑰），一眼看出现在是哪一行。
- **增删行：** 随时添加一行或移除最后一行；只在被移除的那一行里的图标会回到常驻菜单栏。

### 用托盘切换

- **右键点击** Untangle 的菜单栏图标，或者按 **⌥M**，打开 App 托盘。
- 在托盘里按 **1–9** 直接选行，**Tab** 切到下一行，也可以直接点。
- 命令搜索里也有“切换到下一行菜单栏”和“打开菜单栏托盘”，可以绑定自己的快捷键。

### 出问题时

- 整理菜单栏时 Untangle 要借用鼠标，屏幕上会提示“请暂时不要移动”。
- 切换没完成时会自动重试一次；仍然不行就显示全部图标，点 **↺ 重新排布**即可。还不行可以用设置页里的**彻底重建**：让所有图标回到菜单栏，再按行配置重新摆放，配置不会丢。
- 退出 Untangle，菜单栏就恢复原样。

需要 macOS 26、辅助功能和屏幕录制权限。

## 外观与皮肤：换成你喜欢的样子

![同一条标签栏依次换成深色液态玻璃、赛博朋克、手绘铅笔和夜猫皮肤的动画示意。](assets/skins-demo.svg)

> 以前：工具界面千篇一律，和系统风格不搭。

### 自带外观

在**设置 → 通用 → 外观**中选择：

- **液态玻璃：** macOS 26 的玻璃材质，选中处浮起一块发亮的透镜，在卡片、行和标签之间弹着滑过去。
- **经典：** 浮层和设置页面用 Untangle 原来的样式；设置窗口和侧栏在任何外观下都是玻璃。
- **深浅色：** 选液态玻璃时出现。跟随系统、浅色或深色；整个 Untangle 一起变，液态玻璃的浮层和标签栏换成对应的浅色或深色透镜。换到别的外观时，选好的深浅色照样有效。

系统的“减少动态效果”和“增强对比度”都会生效：前者关掉动画，后者给选中的卡片和标签加上描边。

### 皮肤工坊

在外观里选**工坊**，就可以在**设置 → 皮肤工坊**中逐个模块调出自己的皮肤。模块包括切换器、标签栏、Dock 预览、搜索面板、快捷键提示和提示浮窗，每个模块都能单独调：

| 可以调什么 | 选项 |
| --- | --- |
| 基础模板 | 玻璃、极简、赛博朋克 |
| 面板轮廓 / 卡片外形 | 圆角、切角、直角；标签栏还有平行四边形，可调倾斜角度 |
| 颜色 | 强调色、悬停色、背景不透明度、选中文字颜色 |
| 选中标记 | 左侧色条、底部下划线、角标、顶部条，或者不要 |
| 选中高亮 | 高亮背景和边框的强度 |
| 缩略图 | 保持直立、按卡片外形裁切或跟随倾斜；缩略图留白 |
| 标题 | 在缩略图上方或下方、左对齐或居中、字号、字重、是否显示 App 图标 |
| 间距 | 面板留白、卡片间距（紧凑 / 标准 / 宽松） |
| 动效 | 高亮动效强度（无 / 轻柔 / 明显）和速度（慢 / 标准 / 快） |

调好的整套外观可以**导出主题**，存成一个文件分享给别人；导入主题时只换外观，快捷键等功能设置不变。

### 皮肤包

## 设置迁移

> 以前：换了新电脑，要重新录快捷键、重新摆案板。

在**设置 → 诊断**中，把偏好、快捷键、皮肤包、案板（含回收站）和菜单栏分组导出为一个 zip，在新电脑上导入即可，导入后重新打开 Untangle。不包含系统授权、开机启动、缓存、未保存的修改和正在运行的窗口；导入的案板会解除旧桌面绑定，需要时手动打开。文件里有案板记录的文件路径和网址，请妥善保管。

## 其他设置

- **总入口键：** 默认右 Command，也可以录制右 Ctrl、任意单键或组合键（如 Control–Option–K）。
- **快捷键：** 搜索全部命令，录制自己的按键序列或全局快捷键，保存前就能看到冲突。
- **开机启动和语言**在**设置 → 通用**中；**软件更新**在**设置 → 诊断**中。

完整按键见[命令参考](COMMANDS.md)；系统集成和限制见 [macOS 行为说明](COMMANDS.macos.md)。

## 从源码构建

本指南介绍当前 Untangle App。公开的应用源码仍为 **0.0.1**，保留当时的 **Tangler** 名称；编译这份旧源码不会得到当前发布版的全部功能。


需要 macOS 26+、**Swift 6.2+** 及对应 macOS SDK。在仓库根目录运行：

```sh
TANGLER_SIGNING_IDENTITY=- scripts/build-app.sh  # 显式临时签名，仅供测试：build/Tangler.app
```

维护者构建和正式打包统一使用 `Configuration/signing.json` 固定的证书，私钥不包含在源码中。上述命令显式使用 ad-hoc 临时签名，供自行构建测试；重新构建后可能需要重新授予隐私权限。缺少证书时不会自动降级，安装脚本和正式打包也不接受 ad-hoc 签名。无需 Apple 开发者账号。当前构建未经过 Apple 公证；如果 macOS 阻止打开下载的应用，请先确认来源，再按 [Apple 的说明](https://support.apple.com/en-us/102445)操作。

安装包和更新说明见 [GitHub Releases](https://github.com/Q1ngSong/Untangle/releases)。在**设置 → 诊断 → 软件更新**中检查新版本，并选择手动检查、自动检查并提醒，或自动下载与安装。默认每 6 小时检查一次，由你确认安装；开启自动安装后，通常在退出时完成。应用内更新使用 Sparkle，需要配置生产更新公钥并发布更新源。
